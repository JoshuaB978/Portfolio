DEBRIEF: RANSOMWARE_SIMULATION.TXT
Ransomware Simulation
Context: University cybersecurity project developed and tested exclusively in an isolated virtual machine environment.

› Project Overview

Developed a Python-based ransomware simulation to explore the technical components involved in file encryption, cryptographic key management, concurrent file processing, and system-level file operations. A separate decryption program was developed to recover encrypted files using the corresponding private key.

› Cryptography

Implemented AES-256 in CTR mode for file encryption. Used an ephemeral elliptic-curve key with ECDH to establish shared key material, followed by HKDF-SHA256 to derive a symmetric key used to protect the AES encryption key.

› Concurrency & Performance

Implemented a producer-consumer architecture using multiple worker threads and a bounded queue to process files concurrently. File data was processed in 4 MB chunks, and process priority was reduced to limit system resource impact during testing.

› Key Management

Explored the challenges involved in protecting encryption keys while maintaining the ability to recover encrypted data. The project also highlighted the distinction between removing a Python reference to a key and guaranteeing secure memory erasure.

› Lessons Learned

Combined cryptography, operating-system functionality, concurrency, filesystem operations, and programming into a single security-focused project. The project provided practical experience with the tradeoffs involved in designing systems that manipulate large numbers of files while managing cryptographic material.

ENVIRONMENT: Developed and tested exclusively within an isolated virtual machine for academic cybersecurity coursework.
DEBRIEF: VULNERABILITY_ANALYSIS.TXT
Vulnerability Analysis & Reporting Tool
Purpose: Python-based security assessment and reporting tool designed to make vulnerability assessment results easier to collect, normalize, analyze, and review.

› Scan Automation

Built a command-line interface that can launch Nmap and Nikto scans with configurable scan types, targets, ports, and output options. Scan results are saved for later analysis rather than requiring the results to be manually reviewed after every scan.

› Result Parsing & Normalization

Implemented parsers for Nmap XML and Nikto XML/JSON output and normalized the results into a common data structure containing hosts, ports, services, and findings.

› Automated Analysis

Implemented heuristic analysis rules to identify potentially risky services, legacy services, exposed attack surface, service versions requiring further vulnerability review, and common web security misconfigurations.

› Reporting & Search

Built command-line reporting and search functionality with severity filtering, text and regular-expression search, sorting, and Markdown report generation.

› Architecture

The project is organized as a pipeline: scan execution → result parsing → data normalization → automated analysis → risk classification → reporting and search.

NOTE: The tool uses Nmap and Nikto for scanning. Its analysis component applies heuristic rules to scan results and is intended to assist with review rather than replace dedicated vulnerability scanners or manual validation.
