Lab Architecture Case Study

Multi-VM Segmented Enterprise Lab

Environment: Type-2 Hypervisor isolated host running pfSense, VyOS, Ubuntu Server, and Windows 11.

1. Network Topology & Routing

The lab is divided into multiple isolated security zones (DMZ, Internal Workstation Subnet, and Server Farm) managed by a central pfSense firewall and a VyOS routing core.

[ WAN ] --> [ pfSense Firewall (NAT / Strict ACLs) ] | [ VyOS Router Core ] / | \ [ VLAN 10 ] [ VLAN 20 ] [ VLAN 30 ] (Ubuntu) (Win 11) (Services)

2. Key Security Configurations

  • Configured explicit firewall rules blocking lateral movement from workstation VLANs into critical server management ports.
  • Deployed dual-stack IPv4/IPv6 routing to verify firewall behavior across both addressing standards.
  • Monitored inter-VLAN traffic using packet mirroring to detect rogue DHCP and ARP spoofing attempts.
